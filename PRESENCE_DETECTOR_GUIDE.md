# Presence Detector

`Presence Detector` is a C++ texture node under **Textures**. It turns a camera image into four outputs: `Mean Lightness` (0–1), `Coverage %` (the fraction of pixels that pass the threshold), `Present` (a stable boolean), and a black-and-white `Mask` texture. It samples a small image, so it avoids reading the full camera frame back to the CPU. Rebuild and restart the application to make the node available; there is no shader file to copy to `bin/data/Effects/`.

Connect the camera node's texture output to `Presence Detector > Input`. Connect `Mask` to a `Texture Display` node to see exactly which pixels are counted. Use `Present` to drive a switch, trigger, or other control node. The `Mask` is diagnostic and can also be used as a texture elsewhere in a patch.

For a person in front of a mostly black scene, start with `Mode = Lightness`, `Pixel Threshold = 0.12`, `On Area % = 3`, and `Off Area % = 1.5`. The defaults for `Confirm Frames = 2` and `Release Frames = 6` (in the Inspector) suppress single-frame noise and let absence settle a little more slowly. Watch `Coverage %` with the scene empty and occupied: place `On Area %` above the empty reading and below the occupied reading; keep `Off Area %` lower than `On Area %` to prevent flicker. Raise `Pixel Threshold` if the floor or camera noise creates false foreground pixels; lower it if the person is too dark. `Mean Lightness` gives an overall brightness reading, but `Coverage %` is usually a better presence signal because a small bright person can be diluted by a large black background.

For a more stable result when the empty scene has fixed lights or bright patches, choose `Mode = Background Difference`. Make sure the area is empty, then press `Capture Empty` on the node. The mask now marks pixels whose RGB colour differs from that reference by more than `Pixel Threshold`; try `0.06` to `0.10`, then tune the same area percentages. The Inspector's normalized `ROI X`, `ROI Y`, `ROI Width`, and `ROI Height` can exclude parts of the image outside the interaction area. A changed input resolution clears the reference; capture an empty frame again. A significant lighting or camera exposure change also calls for another capture.

Neither mode can reliably detect a person whose pixels look like the background. Lock camera exposure and white balance if possible. For dark clothing against a dark floor, depth or infrared sensing, or a person-segmentation model, would be more robust than visible-light thresholding. This node offers a simple, fast first step and exposes the mask and measurements so thresholds can be tuned on the actual installation.
